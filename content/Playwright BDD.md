# Là gì?
Kết hợp **Playwright** (automation testing framework của Microsoft) với **BDD** (Behavior-Driven Development) để viết test theo dạng kịch bản tự nhiên.

# Tại sao dùng BDD?
- Test case viết bằng ngôn ngữ gần với nghiệp vụ → QA và dev đều đọc được
- Feature files chính là tài liệu sống — vừa là test, vừa là spec

# Trong project này
Feature files viết bằng tiếng Việt → QA review trực tiếp, không cần đọc code.
